# 原 Excel 模板

新上传默认使用 Vercel 可运行的网页编辑模式。解析后的网格用于编辑、变量绑定与 PDF，`grid_config.sourceExcel` 另外保留原文件 base64、SHA-256 和文件名，保存网页修改时不会覆盖该备份。无需修改数据库结构或迁移旧记录；历史网页模板继续按原逻辑打印。

上传 → 选择保留 Excel 版式或 AA/YG 参考图校准 → 网页编辑样式和令牌 → 试打 PDF → 发布。AA/YG 校准会生成固定单页结构并自动放置变量，普通模板只解析第一张工作表。网页 PDF 不绘制编辑器辅助网格线，只绘制模板自身边框。

生成账单时复制原文件，只替换对应工作表的绑定单元格值。样式、合并区域、图片、其他工作表、公式和打印配置不经网格重建。金额使用数值以支持原有公式，请在 Excel 中设置货币格式。明细只使用指定预留行；超容量拒绝生成并提示上传更多预留行的新版本，不自动改行高或移动页脚。所有绑定位置的原始文字会被替换（令牌支持保留前后标签）。

## PDF 与 Vercel

PDF 由应用内的 React PDF 渲染器生成，无需 LibreOffice、Microsoft Office 或额外服务器，适用于 Vercel。网页解析支持 80 行、30 列；超出范围会明确拒绝，不会静默截断。未绑定公式不会在网页中重新计算，因此会提示将结果格绑定为业务变量或下载 Excel 打印。

2026-09-11 之后创建的原件模式模板仍可下载原件和填值 Excel。其 PDF 现通过网页兼容渲染；可以先“另存为网页草稿”微调并试打，原模板、默认模板和历史账单关联均不改变。确认后再发布新草稿。

## 验证与上线

运行 `pnpm run test:native-excel`、`pnpm run type-check` 和 `pnpm test`。新测试比较替换前后 OOXML 压缩包中未修改部分的解压字节，并验证图片、边框、公式、打印配置、原件哈希、日期格式（含 1904 日期系统）、富文本分段字体、单行示例及超容量拒绝。

`node --import tsx scripts/verify-web-excel.ts AA.xlsx YG.xlsx` 可执行 AA/YG 单页校验；输出在独立临时目录，不访问数据库。

本改造不执行数据库迁移、种子或批量更新。上传 AA/YG 为新草稿并核对预览；发布前不会影响现有启用模板。原有只保存网格的模板无法恢复已丢弃的 Excel 原件，需要重新上传。
